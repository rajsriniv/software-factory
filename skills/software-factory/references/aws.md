# AWS delivery profile

Use Terraform through GitHub OIDC with least-privilege roles and protected environments. Validate/format/scan IaC, review the exact plan, bind approval to commit and artifact digest, serialize Terraform state changes, deploy the already-tested artifact, run post-deploy smoke/observability checks, and retain rollback evidence. Require human approval for production, IAM/KMS/network changes, destructive migrations, corrections, and risk waivers. Never store long-lived AWS keys in GitHub.
