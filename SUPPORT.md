# Support

Use GitHub Discussions for design and operating questions and Issues for reproducible defects or scoped enhancements. Security concerns follow SECURITY.md. Include the repository revision, factory configuration with secrets removed, lifecycle stage, relevant event IDs, and failing evidence. This project does not provide an emergency production support SLA.


For controller failures, include sanitized `workflow status`, `workflow doctor`
and relevant `workflow events` output, manifest schema version, assurance and
delivery mode, failing phase and evidence hashes. For knowledge problems, include
the retrieval mode/model or proposal ID/state and relevant `brain-updates events`.
Do not share company source contents, tokens, approval/telemetry keys or raw
sensitive logs. Report the installed distribution version and Git revision;
`software_factory.__version__` currently lags the package metadata.
